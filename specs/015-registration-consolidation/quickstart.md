# Quickstart: Registration Consolidation

**Feature**: 015-registration-consolidation  
**Date**: 2026-04-14

## What Changed

Three separate user registration handlers duplicated the same 7-step sequence (uniqueness checks, password hashing, user creation, verification, persistence, configuration reads, event publishing). This was extracted into a shared `IUserRegistrationService`.

## Before vs. After

### Before (3 independent handlers)

```
RegisterUserHandler         → uniqueness → hash → User.Register → verify → save → config → event
RegisterInternalUserHandler → uniqueness → hash → User.Register → verify → save → config → event
BatchRegisterUsersHandler   → uniqueness → hash → User.Register → verify → save → config → event
```

### After (shared service + thin handlers)

```
RegisterUserHandler         → build request → IUserRegistrationService.RegisterAsync → return Success()
RegisterInternalUserHandler → build request → IUserRegistrationService.RegisterAsync → return Result<RegisterInternalUserResult>
BatchRegisterUsersHandler   → foreach row: check existing → build request → IUserRegistrationService.RegisterAsync → collect results
```

## How to Use the Shared Service

### Public Self-Registration

```
Request:
  Email, Country, NationalId, FirstName, LastName, Password (user-provided)
  ProjectExternalId: null
  EmailVerification: Required
  EnrollmentVariant: "SelfRegistration"
  RequirePasswordReset: false
```

### Admin Single-User Registration

```
Request:
  Email, Country, NationalId, FirstName (optional), LastName (optional), Password (admin-provided)
  ProjectExternalId: required Guid
  EmailVerification: Required or Skipped (based on admin choice)
  EnrollmentVariant: "FullFlow"
  RequirePasswordReset: false
```

### Batch Registration (per new row)

```
Request:
  Email, Country, NationalId, FirstName, LastName, Password (auto-generated by batch handler)
  ProjectExternalId: required Guid
  EmailVerification: Skipped
  EnrollmentVariant: "FullFlow"
  RequirePasswordReset: true
```

## What Was Removed

- `UsersController.Enroll` (GET + POST actions) — replaced by `RegisterInternal`
- `EnrollUserViewModel` — replaced by `InternalRegistrationViewModel`
- `Enroll.cshtml` — replaced by `RegisterInternal.cshtml`
