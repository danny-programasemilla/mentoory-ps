## Implementation Phases

### Phase 1: Dashboard View Rewrite (FR-001 through FR-005)

**File**: `Mentoory.Web/Areas/Administration/Views/Dashboard/Index.cshtml`

**Changes**:

1. **Fix card-status-start pattern** (FR-001, FR-003): Replace incorrect `class="card card-status-start border-start border-primary border-3"` with correct Tabler child-div pattern:
   ```html
   <div class="card">
     <div class="card-status-start bg-primary"></div>
     <div class="card-body">...</div>
   </div>
   ```
   Apply to all 3 navigation cards (Proyectos → `bg-primary`, Usuarios → `bg-success`, Carga Masiva → `bg-info`).

2. **Enhance stat card typography** (FR-002, FR-008): Change metric display from `<div class="font-weight-medium">` to a more prominent pattern using `<div class="h1 mb-0">` for the count and a separate `<div class="text-secondary">` for the label.

3. **Fix card footer layout** (FR-005): Ensure card footers render links horizontally. The current footer structure is correct (`<a>` with text + icon), but the card-status-start misuse was causing width squeeze. The fix in step 1 resolves this.

4. **Preserve empty state** (FR-004): The `@if (Model.UserCount == 0 && Model.ProjectCount == 0)` block and its `.empty` component remain unchanged.

5. **Add data-testid attributes** for E2E test stability:
   - `data-testid="stat-card-users"` on the users stat card
   - `data-testid="stat-card-projects"` on the projects stat card
   - `data-testid="nav-card-projects"` on the Proyectos nav card
   - `data-testid="nav-card-users"` on the Usuarios nav card
   - `data-testid="nav-card-batch"` on the Carga Masiva nav card

### Phase 2: CSS Polish (FR-006 through FR-010)

**File**: `Mentoory.Web/wwwroot/css/mentoory.css`

**Add new section** after the existing `/* ── Avatar ── */` block:

1. **Card shadows** (FR-006): Add subtle `box-shadow` to `.card` at rest, with `transition: box-shadow 0.2s ease, transform 0.2s ease`.

2. **Card hover lift** (FR-007): Add `.card-link-hover` class (applied to navigation cards) with `:hover` state that applies `transform: translateY(-2px)` and deeper shadow.

3. **Stat metric typography** (FR-008): Style `.h1` inside `.card-sm .card-body` for visual weight if needed beyond Tabler defaults.

4. **Brand warmth** (FR-010): Verify existing avatar, status-strip, and link styles use coral. Add any missing accent rules.

**Important**: Use Tabler CSS variable names (`--tblr-*`) for consistency. Query Context7 for correct variable names before writing CSS.

## Risk Mitigation

| Risk | Mitigation |
|------|------------|
| Global `.card` shadow affects other pages unexpectedly | Use Tabler's existing shadow utilities where possible; visual QA on 6 pages |
| E2E tests flaky with layout assertions | Use `data-testid` attributes, not CSS class selectors; assert visibility not pixel positions |
| `card-status-start` child-div pattern differs between Tabler versions | Verified against Tabler v1.4.0 docs via Context7 — child `<div>` with `bg-*` class is the correct pattern |
