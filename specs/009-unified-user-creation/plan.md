# Implementation Plan: Unified User Creation with Configurable Onboarding

**Branch**: `009-unified-user-creation` | **Date**: 2026-04-12 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/009-unified-user-creation/spec.md`

## Summary

Replace the fragmented admin user creation experience (two individual forms + batch upload) with a unified individual form and improved batch flow. Both derive project binding from session context (spec 008) and offer two configurable onboarding toggles (skip email verification, skip invitation acceptance). The 4 toggle combinations map to existing infrastructure: `UserRegisteredEvent.RequiresVerification` + `EnrollmentVariant` control the flow, and the existing `ProjectInvitation` aggregate in the Tenant domain handles invitation lifecycle. Key additions: new `CreateUserCommand`/`BatchCreateUsersCommand` in Access domain, `RequiresAcceptance` field on `ProjectInvitation`, public onboarding pages with password setup, and an onboarding status column on the admin users list.
